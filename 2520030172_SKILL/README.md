This experiment focuses on analyzing process abstraction in Linux by using system calls such as fork() and exec(). The fork() system call is used to create a new child process from a parent process, helping us understand the relationship between parent and child processes. The exec() family of system calls is used to replace the current process with a new program. The process hierarchy can be inspected using tools such as pstree, which displays the parent-child relationships between processes. System call tracing can also be performed using strace to observe the system calls executed by a program.
